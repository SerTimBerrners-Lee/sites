# SEP:Chat landing

Адаптивная локальная верстка по десктопному и мобильному макетам Figma.

## Запуск

Откройте `chat/index.html` двойным щелчком в Finder. CSS, скрипт и изображения подключены относительными путями и работают без локального сервера.

Если нужен адрес `localhost`, из папки `chat` запустите:

```sh
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.

Навигация в шапке прокручивает страницу к разделам; целевые кнопки открывают форму. Нижние формы принимают данные на странице. Валидация, согласие и просмотр документов работают локально. Для реальной отправки заявки нужен серверный обработчик; до его подключения интерфейс не выдаёт ложное подтверждение отправки.
