# SEP:Chat landing

Адаптивная локальная верстка по десктопному макету Figma. Мобильная компоновка разработана для этого проекта.

## Запуск

Из папки `sep-chat-landing`:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

Навигация в шапке прокручивает страницу к разделам; целевые кнопки открывают форму. Нижние короткие формы переносят введённые данные в модальное окно. Валидация и согласие работают локально. Для реальной отправки заявки нужен адрес серверного обработчика; до его подключения интерфейс не выдаёт ложное подтверждение отправки. Ссылки на юридические документы ожидают актуальные URL.
